HOW TO APPLY
1. Extract this ZIP.
2. Open PowerShell in your TK Fireworks project root (the folder containing package.json).
3. Run the included script using its full path, for example:
   powershell -ExecutionPolicy Bypass -File "C:\path	o\APPLY_SEO_V2.ps1"
4. Run: npm run build
5. If build succeeds, commit/push to GitHub and let Netlify deploy.
6. In Google Search Console, inspect https://tkfireworks.com/ and request indexing once.

The installer creates a .seo-v2-backup-TIMESTAMP folder before modifying files.
